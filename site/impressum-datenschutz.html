Datenschutz

Diese Website erhebt so wenige Daten wie möglich. Sie unterliegt dem Bundesgesetz über den Datenschutz (DSG) der Schweiz.

Keine Cookies, keine Auswertung
Die Website setzt keine Cookies und verwendet keine Dienste, die Besuche auswerten oder Werbung zeigen. Sie bindet keine Inhalte sozialer Netzwerke ein.
Keine Dienste anderer Anbieter
Schriften, Bilder und Skripte liegen auf demselben Server wie die Seiten. Beim Lesen gehen keine Daten an andere Anbieter als den Dienst, der die Website ausliefert (siehe «Protokolle beim Betrieb»).
Protokolle beim Betrieb
Die Website wird über den Dienst Netlify (Netlify, Inc., USA) ausgeliefert. Beim Aufruf einer Seite fallen bei Netlify technisch notwendige Angaben an. Nach Angaben von Netlify können dazu insbesondere IP-Adresse, Gerätetyp, Betriebssystem sowie Browsertyp und -version gehören. Diese Angaben können ausserhalb der Schweiz bearbeitet werden, insbesondere in den USA. Netlify nennt dafür unter anderem Standardvertragsklauseln und das Swiss-U.S. Data Privacy Framework. Weitere Angaben enthält die Datenschutzerklärung von Netlify.
Frühere Einträge im Browser
Eine frühere Fassung dieser Website bot ein Werkzeug für persönliche Einträge an. Falls Sie es genutzt haben, können Ihre Einträge noch lokal im Browser auf Ihrem Gerät liegen. Sie wurden nicht an die Website übertragen. Entfernen können Sie sie in den Einstellungen Ihres Browsers.
E-Mail an die Fachstelle
Wenn Sie der Fachstelle schreiben, verwendet sie Ihre Angaben, um Ihnen zu antworten. Wenn Sie eine Nachricht senden, werden Absenderadresse, Inhalt und gegebenenfalls Anhänge über Ihren E-Mail-Dienst an den empfangenden Dienst übermittelt. Gewöhnliche E-Mails sind nicht durchgehend verschlüsselt. Schreiben Sie nur, was Sie auf diesem Weg mitteilen möchten.
Links auf andere Websites
Wenn Sie einem Link auf eine andere Website folgen, gelten dort deren Regeln zum Datenschutz.
Ihre Rechte
Je nach anwendbarem Recht und unter den jeweiligen gesetzlichen Voraussetzungen können Sie insbesondere Auskunft über Ihre Daten verlangen, ihre Berichtigung oder Löschung verlangen und ihrer Bearbeitung widersprechen.
Änderungen
Diese Angaben können angepasst werden, wenn sich rechtliche Anforderungen oder die Website ändern. Es gilt die jeweils aktuelle Fassung.
